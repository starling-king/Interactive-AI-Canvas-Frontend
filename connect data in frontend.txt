* **Businessman Insight:** This is a crucial First-Order engineering decision. If a user has 50 canvases, downloading 50 massive JSON graphs at login would crash the browser. We only download the "menu items" first.

### Phase 2: The Dashboard Selection

1. The user is now looking at their Dashboard. They see a grid of cards built from the `workspaces` array inside `useWorkspaceStore`.


2. The user clicks a card (e.g., "E-commerce Pipeline").

### Phase 3: The Deep Hydration (`CanvasWorkspace.jsx`)

This is where the heavy lifting happens. `CanvasWorkspace.jsx` is just a dumb, physical "body." It does not think; it only renders what Zustand tells it to render.

1. **Mounting:** `CanvasWorkspace.jsx` mounts and reads the `workspaceId` from the URL.
2. **The Fetch:** It calls `fetchCanvas(workspaceId)` from your `useCanvasActions.js`.


3. **The Database Query:** This hits your backend `GET /api/v1/canvas/:workspaceId`. The backend pulls the massive JSON payload containing `nodesData` and `edgesData` for that specific project.


4. **The Brain Injection (`useCanvasStore`):** The action takes that raw JSON and injects it straight into `setCanvasState()` inside `useCanvasStore`.



### Phase 4: The Kinetic Render

The instant `useCanvasStore` updates, `CanvasWorkspace.jsx` reacts.

1. React Flow reads the `nodes` array.


2. It looks at the `type` string (e.g., `"node_table"`). It checks our `nodeTypes` dictionary and sees that `"node_table"` maps to `TableNode.jsx`.


3. It mounts `TableNode.jsx`, passing down the specific data (database columns, formulas, slider values).


4. The canvas appears on the screen exactly as the user left it.

### Phase 5: The AI Orchestration Flow

When the user clicks "Generate with AI" while inside this workspace:

1. `AiPromptModal.jsx` opens. The user types a prompt and hits Generate.


2. `submitPrompt()` fires, sending the prompt and the current `workspaceId` to the backend.


3. The backend puts the job in BullMQ, Gemini processes it using our new `MASTER_RULEBOOK`, and the backend saves the new JSON graph into the database under that `workspaceId`.


4. The frontend polls the server. The moment the server replies with `200 OK` and the new JSON payload, `useAiActions.js` bypasses everything and directly calls `setCanvasState()` to inject the new AI data into the canvas.


5. The UI modal closes automatically, and React Flow instantly animates the new AI-generated architecture onto the screen.
